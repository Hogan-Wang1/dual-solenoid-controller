# 既有控制电路桌面审查与修改意见

## 1. 审计范围和资料依据
### 1.1 审查目的
本次审查围绕双通道电磁阀控制系统的既有电路资料，核对供电、参数控制、脉冲时序及负载驱动方案与项目要求之间的关系，记录有依据的问题、潜在风险及资料缺口，为原理图修改沟通提供参考。
审查重点是判断现有资料是否足以支持相关制作决策，不以“未在图纸中展示”直接推断某项功能或保护不存在，也不预设既有方案必须整体重构。

### 1.2 资料依据
|资料名称|本次用途|版本及使用限制|
|---|---|---|
|《项目要求》|作为功能、参数范围及交付要求的需求来源，由本人依据老板要求撰写|用户于2025.10编写初稿，于2026.10检查后上传|
|《附件5.控制器电路图》|核对逻辑供电、参数输入、主控接口及驱动级的器件标注和连接|未获得授权，不公开|
|《附件6.外部连接电路图》|核对外部电源、控制器、电磁阀及面板接口之间的连接关系|未获得授权，不公开|

### 1.3 工作归属说明
个人历史参与包括需求编写、未被采用的初步LabVIEW及原理图方案、既有原理图分析，以及与商家沟通修改要求。本次收尾新增的分析，不归入当时已完成的工作；

本报告为基于现有资料的桌面设计审查，未进行改版后的上电验证，未参与样机搭建与联调，也不构成硬件输出、时序性能或真实电磁阀响应的验证结论。对外展示是不包含未获得授权的原理图等内容

## 2. 系统架构与需求对应

采用“Arduino 产生基准时钟 + 74HC160 计数器链硬件分频”的方案生成两路低频脉冲。
电源部分：230VAC → 变压器 → 整流滤波 → LM340T5 产生 +5V，同时两个 0-30V/3A 线性电源给电磁阀供电。
驱动部分：Arduino 脉冲 → 2N2222 → IRF9210 高边 P-MOS → 电磁阀，续流管为 1N4448。

## 3. 审计方法
本报告采用基于现有资料的桌面审查方法，沿“需求—电路连接—器件参数—功能实现—资料一致性”的路径进行核查。结论类型按照高风险、中风险、低风险和无法判断，四级分类。影响与优先级按照P1：影响安全或相关制作决策，应优先确认或处理，P2：影响功能、可靠性或验收，P3：文档、标识、装配一致性或可维护性改进，三级分类。

|---|---|---|---|---|---|

### 4.2 定时和脉冲模块
|编号|问题|结论类型|依据|影响及优先级|修改或核查建议|
|---|---|---|---|---|---|
|TIM-01|U1-U4，U6-U17级联链长|高风险|长级联走线易受干扰并累积不同步|P1：影响是否可直接推进制作，需先确认或处理|废除拨码级联，参数改由上位机串口下发；若保留需加缓冲/滤波并重布走线|

### 4.3 控制核心
|编号|问题|结论类型|依据|影响及优先级|修改或核查建议|
|---|---|---|---|---|---|
|CTL-01|TX/RX接反|高风险|常见TX接RX，此处需要核查两端实际连接，依据实际判断|P1：影响是否可直接推进制作，需先确认或处理|TX接RX、RX接TX，并核对丝印|
|CTL-02|RTS误作复位|高风险|Arduino自动复位通常用DTR经100nF耦合到RESET；RTS不是标准复位专用信号，但需依据实际判断|P1：影响是否可直接推进制作，需先确认或处理|改用DTR，并核查C12复位耦合电容连接|
|CTL-03|D3/D7软件脉冲抖动|高风险|旧固件用delay()/millis()软件生成脉冲，受中断和串口阻塞影响，抖动大、无硬件定时器、两路不同步，无法满足1ms步长|P1：影响是否可直接推进制作，需先确认或处理|改用硬件定时器输出，并加保护与状态机|
|CTL-04|D10/D11阻塞脉冲|高风险|D10作74HC165 CP时钟，需软件翻转；与D3/D7软件脉冲生成互相阻塞，造成时序抖动|P1：影响是否可直接推进制作，需先确认或处理|废除74HC165，改串口参数下发|
|CTL-05|C12复位电容接错|高风险|C12为100nF复位耦合电容，应接DTR，否则自动复位/下载不稳定，但需依据实际情况判断|P1：影响是否可直接推进制作，需先确认或处理|连接DTR，核查C12取值与复位时序|

### 4.4 驱动模块
|编号|问题|结论类型|依据|影响及优先级|修改或核查建议|
|---|---|---|---|---|---|
|DRV-01|P-MOS高边驱动复杂|高风险|IRF5210为P-MOS高边，需2N2222反相拉低栅极；高边无TVS，阀感性负载反电动势易击穿；导通电阻大、发热严重；IRF5210常见最大额定值为±20V，面对30V电源，可能超限|P1：影响是否可直接推进制作，需先确认或处理|改用低边N型MOSFET|
|DRV-02|续流管额定不足|高风险|1N4448连续电流约100mA，而阀吸合电流200-400mA；续流时超额定，存在烧毁并导致MOSFET击穿风险|P1：影响是否可直接推进制作，需先确认或处理|可以考虑更换SS34（3A/40V）或1N5819（1A/40V），并加TVS，但需依据实际情况判断|
|DRV-03|栅极上拉过小|中风险|R33/R52阻值太小，与IRF5210栅极电容形成RC延迟，开关沿变缓，并可能误触发|P2：影响功能、可靠性或验收|改为10k-100k，并在基极/发射极加下拉电阻防误触|
|DRV-04|去耦容量偏低|中风险|C13/C19容量略低，瞬态电流和干扰余量不足，靠近MOSFET可改善|P2：影响功能、可靠性或验收|改为100μF电解 + 100nF陶瓷，并尽量靠近MOSFET|
|DRV-05|反相器随重构核查|低风险|2N2222作P-MOS栅极反相器；若改低边N-MOS则不再需要|P3：文档、标识或可维护性改进|改低边则取消；保留则核查基极电阻|
